# ПП Генератор — Бизнес Груп-11 ЕООД

Уеб приложение за генериране на Приемо-Предавателни Протоколи от HomeMax поръчки.

## Как се публикува (еднократно)

### 1. Качи кода в GitHub

1. Отвори https://github.com/radyyy3-blip/Zelenko
2. Натисни **Add file → Upload files**
3. Качи всички файлове от тази папка (запази структурата на папките)
4. Натисни **Commit changes**

### 2. Публикувай с Vercel

1. Отвори https://vercel.com и влез с GitHub акаунта си
2. Натисни **Add New → Project**
3. Избери репото **Zelenko**
4. Натисни **Deploy**
5. След ~2 минути получаваш линк като `zelenko.vercel.app`

## Как се ползва

1. Отваряш линка в браузъра
2. Въвеждаш датата на доставката
3. Качваш PDF поръчките от HomeMax (може няколко наведнъж)
4. При нужда коригираш количества директно в таблицата
5. Натискаш **Генерирай ПП** → файловете се свалят автоматично

## Локално стартиране (за тест)

```bash
npm install
npm run dev
```

Отвори http://localhost:3000
